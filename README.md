# Sistema Contable

## Descripción:

Este repositorio contiene un programa desarrollado durante las clases de Programación. Como ejemplo, incluye un formulario realizado en Java utilizando la biblioteca Swing.

## ¿De qué trata el proyecto?:

El programa permite ingresar el nombre y la edad de una persona y, al presionar un botón, muestra un mensaje con la información ingresada.

## ¿Cómo utilizarlo?:

1. Descargar el archivo `archivo.java`.
2. Abrirlo en un IDE como NetBeans, Eclipse o IntelliJ IDEA.
3. Compilar y ejecutar el programa.
