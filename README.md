# Formulario en Java

## Descripción del proyecto

Este proyecto consiste en un formulario desarrollado en Java utilizando la biblioteca Swing. Permite ingresar el nombre y la edad de una persona y, al presionar un botón, muestra un mensaje con los datos ingresados.

## ¿Cómo utilizarlo?

1. Descargar el archivo `Ejercicio1.java`.
2. Abrirlo en un entorno de desarrollo como NetBeans, Eclipse o IntelliJ IDEA.
3. Compilar y ejecutar el programa.
4. Escribir el nombre y la edad.
5. Presionar el botón **"Mostrar datos"** para visualizar el resultado.

## ¿Quién lo creó?

Creado por: **[Tu nombre completo]**

## ¿Qué hace?

El programa muestra una ventana con dos campos de texto para ingresar el nombre y la edad. Al hacer clic en el botón, aparece un mensaje con la información ingresada por el usuario.
